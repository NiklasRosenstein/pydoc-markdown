When rendering a page, rename reference-style link labels that more than one docstring defines, so their links no longer point to the first definition. Set `namespace_reference_links: false` to disable, or `namespace_reference_links_in_objects: true` to also rename labels in individually rendered objects (e.g. Novella). (issue [#125](https://github.com/NiklasRosenstein/pydoc-markdown/issues/125), @NiklasRosenstein)
