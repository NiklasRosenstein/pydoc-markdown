# Source linkers

Source linkers add "view source" links to the output. Configure one as the `source_linker` of the Markdown renderer;
see the [Source links guide](../guides/source-links.md).

| --- | --- |
| `github` | {@pylink pydoc_markdown.contrib.source_linkers.git.GithubSourceLinker} |
| `gitlab` | {@pylink pydoc_markdown.contrib.source_linkers.git.GitlabSourceLinker} |
| `gitea` | {@pylink pydoc_markdown.contrib.source_linkers.git.GiteaSourceLinker} |
| `bitbucket` | {@pylink pydoc_markdown.contrib.source_linkers.git.BitbucketSourceLinker} |
| `git` | {@pylink pydoc_markdown.contrib.source_linkers.git.GitSourceLinker} |
